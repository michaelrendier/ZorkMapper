# duhmap: the console map explorer, derived from Duh DRAW

`duhmap` is a modification of **Duh DRAW** (Ben Fowler 1996; Pekka Enberg 2002-03), the Linux open-source clone of TheDraw. The editing core is replaced by a map explorer for the maps ZorkMapper writes; the program shape (init, event loop, a key reader that treats ESC+letter as Alt-letter, the bottom status line and function-key strip, the directory dialog) is Duh DRAW's, now drawn through ncursesw.

**Licence.** Duh DRAW is GNU GPL version 2; `LICENSE` is its licence text, and the original `CREDITS.duhdraw`, `HISTORY.duhdraw` and `README.duhdraw` are kept. This directory as a whole is therefore **GPL v2** (not v3). The rest of ZorkMapper (Python) is GPL v3 and is a separate program; the two only exchange files (`.zmap`).

**Install:** `make && sudo make install` puts it in `/usr/bin/zork-map` (`sudo make uninstall` removes it); run `zork-map` from anywhere. It reads **`~/.zorkmapper/config`** at run time (maps folder, the mapper's home, panel percentages; `ZORKMAPPER_DIR` moves the root) and opens maps from `~/.zorkmapper/maps/`. **Build only:** `make` (gcc, libncursesw). **Run:** `./duhmap ../ASCIIArt/zork1.zmap` (UTF-8, 256 colours, about 100 x 30 or larger). With no argument it lists `*.zmap` in the maps folder (`ZORKMAP_DIR` overrides it). `./duhmap --check FILE` parses a map and prints a summary.

**Navigation follows the drawn map, not the game's exit table.** From the room's square the cursor steps in the pressed direction along the drawn pathway (`==` `||` `//` `\\`, crossings `XX` `++`) to the room at its end; a superscript label (`²³`) at the end of a short stub names its room; a one-way arrow (`=>` `<=` `^^` `vv` and the diagonal arrows) can be walked only the way it points, so going back along a one-way line is INVALID DIRECTION, as is a blank square, a wrong kind of glyph, or a maze word (`MAZE: NOT MAPPED`). Pathway squares are only `/ \ | =` (and arrows, `XX`/`++` crossings, `U`/`D` markers); labels always sit in the square beyond the line, never in place of it.

**Teleports and before/after rooms.** `t` (or Go > Teleport) in a room with a teleporter (marked `~` in the list; e.g. the Zork I mirror rooms, the rainbow) puts a bright red **TELEPORT? Y/n** across the viewport and waits: Y or Enter goes, n or Esc cancels, Tab cycles destinations. A room whose description changes after an **irreversible** event (the cyclops gone, the grate revealed, the mirror broken, the Zork III ring stolen) is marked `*` in the list and has a second version: `*` (Shift-8) switches between BEFORE and AFTER ({flag}), which the side panel states. Both are read from the game's own ZIL by `zorkmapper/events.py` (teleports: `<GOTO ,ROOM>` in an object's action or under `<EQUAL? ,HERE ,ROOM>`, not already an exit, plus a hand-checked `data/teleports.json` for moves the ZIL builds indirectly; versions: M-LOOK text on a global flag that is set true and never set false anywhere).

**Keys.** Arrows: N, S, W, E. **Shift-Up UPW, Shift-Down UPE, Shift-Left DW, Shift-Right DE** (up and down are drawn as diagonals; the side chooses which diagonal when a room has two). `y u b n`: NW NE SW SE. Tab / Shift-Tab: next / previous room. Home / End: start / last room. PgUp / PgDn: a level up / down (the nearest room on that level). F2 / F3 / F4: legend, sidebar, status. ESC: the menu bar (Files, Go, View, Levels, Help), after TheDraw. Alt-O open, Alt-M map a game (runs `python3 -m zorkmapper --map PATH` in `$ZORKMAPPER_HOME`), Alt-G go to a number, Alt-H help, Alt-X quit. With no exit in a direction the cursor moves to the nearest room that way on the sheet and says so.

**Screen.** Every size is recomputed from the terminal's real size, also while it runs (maximize, un-maximize, a TV over HDMI): legend 16%, sidebar 30%, status 22% of the width/height (`panel_*` in the config), each panel in its own box outline. The current room is always at the centre. **Automatic zoom:** the map's spacing grows with the viewport (zoom 1 is the file's canvas; zoom k spreads each grid step over k+1 rows and 2(k+1) columns, passages stretched, diagonals re-drawn), chosen so about 18 x 9 squares stay in view; `+` / `-` set it by hand, `=` returns to auto. **Contrast rule:** every surface has an explicit background; black text on light backgrounds, white text on dark ones, never light on light or dark on dark (menus and dialogs are black on light grey with the selection white on blue; panels white on near-black; elevation squares black on the bright colours, white on the dark ones). **Selected room:** its square keeps its elevation colour and number and is bracketed by bright red `[ ]`. The legend shows elevation: white = ground level (the start room), bright rainbow going up, dark rainbow going down.

**Not here yet:** editing (palette, drawing), the elevation-layer-only view, the QGraphicsScene / PyQt6 / OpenGL versions.
